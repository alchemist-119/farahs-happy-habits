# 🌸 Farah’s Happy Habits

## 妹妹的生活自我管理漫畫
### 讓大腦少一點忙，讓生活更順

> **不用一次做到完美。**  
> **先發現，再調整。**  
> **會用方法幫自己，就是進步。**

# 🌟 這一組要練什麼？

Farah 最近有幾件很適合開始練習的小事：

1. 有時候會不知不覺吃手
2. 放學時容易忘記整理學校抽屜
3. 老師說「現在抄筆記」時，腦袋可能還在處理前面的資訊
4. 為了銜接國中生活，慢慢練習專心、快速啟動並有效率地完成作業
5. 做完事情後，學會檢查、整理與收尾
6. 看見自己的身體與學習需要，練習主動向大人說明
7. 發現關於自己的作品或簽名不正確時，先說事實，再提出合理需求

這些事情看起來不一樣，其實都可以使用同一個方法：

> **發現 → 看清楚下一步 → 用工具幫自己**

這不是要 Farah 變成最快的人，而是讓她慢慢學會：

> **我知道自己現在卡在哪裡。**  
> **我也知道可以怎麼幫自己。**

# 🎨 漫畫 07｜把「抄筆記」拆成第一步

![漫畫 07｜把「抄筆記」拆成第一步](07-first-step-for-notes.png)

> **日期 → 標題 → 關鍵詞**

事情太大時，大腦容易卡住；把它拆成清楚的第一步，就容易啟動。

---

# 🎨 漫畫 08｜筆記不是把老師的話全部搬走

![漫畫 08｜筆記不是把老師的話全部搬走](08-compressed-notes.png)

先找最重要的三個詞，再用箭頭和符號壓縮：

> **temp ↓ → 水蒸氣凝結 → 雲**

筆記不是抄得最多，而是之後看得懂，而且能把內容想回來。

# 🎨 漫畫 17｜我需要午休，我可以自己說

![漫畫 17｜我需要午休，我可以自己說](17-self-advocacy-midday-rest.png)

Farah 發現自己如果中午沒有休息，下午就會精神不濟。她沒有只靠忍耐，也沒有等別人猜到，而是主動向輔導老師說明自己的需要。

> **我先發現自己的需要，再清楚說出來。**

這不是找麻煩，而是學會照顧自己。

# 🎨 漫畫 18｜這不是我畫的，我想自己補上

![漫畫 18｜這不是我畫的，我想自己補上](18-self-advocacy-own-card.png)

Farah 發現班級卡片上的自畫像與簽名不是自己完成的。她先分清楚「事實」與「猜測」，再親自向班導說明，希望自己畫一個、自己簽名並補上。

> **關於我的東西，我希望由我自己來完成。**

這不是告狀，也不必先證明別人有惡意；平靜表達事實與需求，就是在捍衛自己的權利。

# 🌸 Farah’s Happy Habits 小口訣

## 1｜手跑到嘴巴時

> **發現 → 放下 → 換動作**

可以換成抱抱枕、捏小軟球、拿筆、喝水或雙手交握。

## 2｜放學整理時

> **桌面 → 抽屜 → 書包 → 地板**

抽屜只分：**帶回家／留學校／垃圾**。

## 3｜老師要我開始做事時

> **先找第一步：日期 → 標題 → 關鍵詞**

## 4｜筆記太多時

先問：「這段最重要的三個詞是什麼？」再使用關鍵詞、箭頭與符號。

## 5｜作業開始前

> **拿作業 → 準備文具 → 第一題**

## 6｜做作業時

> **一次一科／先專心 15 分鐘／卡太久就打 ? 先跳過**

## 7｜作業做完後

> **檢查 → 收書包 → 桌面 Reset**

## 8｜我有需要或發現不對時

> **看見需要 → 說明事實 → 提出希望怎麼修正**

# 🌱 為國中生活慢慢準備的能力

1. 聽到任務後能開始
2. 知道第一步是什麼
3. 一次專心處理一件事
4. 能把大任務拆成小步驟
5. 知道自己還剩多少工作
6. 遇到卡題不會整份停住
7. 能在合理時間內完成
8. 做完後會檢查和收尾
9. 能用提示卡、流程、符號幫助自己
10. 忘記或卡住後，知道怎麼重新開始

# 💡 給大人的提醒

Farah 有時候需要多一點時間，把「聽到的內容」轉換成「可以開始執行的步驟」。

比起一直說「快一點」、「怎麼還沒開始？」或「妳又忘記了」，更有效的是問：

> **「第一步是什麼？」**

也可以直接提供很短的視覺提示：

> **日期 → 標題 → 關鍵詞**  
> **桌面 → 抽屜 → 書包 → 地板**  
> **拿作業 → 文具 → 第一題**

---

# 🌼 我們不是要把 Farah 變快

真正的目標不是永遠不能忘，也不是一定要比別人快，而是讓每一個步驟越來越自動。

當開始作業不用想太久、整理書包不用靠媽媽提醒、抄筆記知道怎麼抓重點、卡住知道怎麼跳過再回來，Farah 自然就會變得：

> **更快、更穩、更獨立。**

---

# 🌸 Happy Habits 的核心

> **快，不是一直催自己；快，是讓流程越來越順。**

> **獨立，不是什麼都不用幫忙；而是越來越知道怎麼幫自己。**

> **Happy Habits 不是要求完美，而是每天多一點點會照顧自己的方法。**
